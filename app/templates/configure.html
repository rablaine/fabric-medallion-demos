Configure {{ vertical.name }} Deployment

Set your deployment parameters, then download a customized package that you can run with your own Azure CLI credentials.

What you'll get & what happens when you run it

You fill in the form, click Download Deployment Package, and get a zip with your settings baked in. Inside the zip is deploy.cmd. Running it prompts for your Azure account + subscription, then deploys everything in order:

  1. Resource group in your chosen region
  2. Azure SQL (serverless) + the retail schema
  3. ADLS Gen2 with raw + curated containers
  4. Fabric F2 capacity (you as admin)
  5. Bronze workspace + lakehouse in Fabric
  6. Seed notebook uploaded and executed — populates SQL with a fiscal quarter of data (5k customers, 1.5k products, 50k orders) and drops 90 days of supplier Parquet + marketing CSV files into ADLS raw/
  7. SQL Mirror of every retail table into the bronze lakehouse as Delta — real-time, no pipeline needed
  8. OneLake shortcut from Files/raw → your ADLS raw/ container

Checkpoint: at this point you have a fully populated bronze layer. Open Fabric, find your bronze workspace, and browse the mirrored tables + raw files.

Next phase (run when ready): medallion build-out — silver + gold workspaces, bronze→silver and silver→gold notebooks, an initial-load pipeline, an incremental-load pipeline, and a "simulate-incremental" notebook that fabricates new daily activity. You run the initial load once, then trigger incremental loads on demand.

When you're done, pause the Fabric capacity (or delete the RG) to stop the bill.
