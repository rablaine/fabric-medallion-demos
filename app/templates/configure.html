Configure {{ vertical.name }} Deployment

Set your deployment parameters, then download a customized package that you can run with your own Azure CLI credentials.

What you'll get & what happens when you run it

You fill in the form, click Download Deployment Package, and get a zip with your settings baked in. Inside the zip is deploy.cmd. Running it prompts for your Azure account + subscription, then deploys an end-to-end retail data estate in one shot (typically 25-40 minutes).

Azure infrastructure (Bicep)

  1. Resource group in your chosen region
  2. Azure SQL serverless Gen5 with the retail OLTP schema + change tracking
  3. ADLS Gen2 with raw + curated containers (supplier Parquet, marketing CSV land here)
  4. Event Hubs Standard for live clickstream
  5. Azure Functions (Flex Consumption) emitting synthetic clickstream into Event Hubs
  6. Fabric F8 capacity with you as admin

Fabric: bronze workspace

  1. Bronze workspace + lakehouse + workspace identity
  2. Seed notebook populates SQL with a fiscal quarter of data (customers, products, orders, payments, shipments, returns, reviews) and drops 90 days of supplier Parquet + marketing CSV into ADLS raw/
  3. SQL Mirror of every retail table into the bronze lakehouse as Delta — real-time, no pipeline
  4. OneLake shortcut Files/raw → ADLS raw/
  5. Eventhouse + KQL DB with a Clickstream table; Eventstream wires Event Hubs → KQL DirectIngestion
  6. Clickstream backfill notebook seeds ~2M historical events into KQL
  7. All pipelines live here (orchestration hub): weather ingest, bronze initial / incremental load, silver initial / incremental load, gold initial / incremental load

Fabric: silver workspace

  1. silver_raw lakehouse with shortcuts to the bronze mirror tables
  2. silver_curated lakehouse with full-load notebooks (retail, weather, clickstream, HR, ops) that build conformed dimensions and curated facts
  3. Notebooks only — the silver pipelines that run them live in the bronze workspace

Fabric: gold workspace

  1. Gold warehouse with DDL + stored procedures that rebuild gold star schema (fact_orders, fact_payments, fact_shipments, fact_returns, fact_reviews, dim_store, dim_product, dim_customer, dim_employee, …)
  2. Shortcut lakehouse back to silver_curated so the gold sprocs can CTAS from curated data
  3. Semantic models (Direct Lake): Retail Sales, HR & Workforce
  4. Power BI reports: Retail — Sales Overview, Retail — Operations Pulse, HR — Workforce Overview, HR — Attrition & Tenure (organized into Retail / HR folders)
  5. Data agents for natural-language Q&A over the gold semantic models

What you can do when it's done: open Fabric, browse the three workspaces, run the reports, chat with the data agents, and trigger the incremental pipelines (or the simulate-incremental notebook) to fabricate a new day of activity and watch it propagate bronze → silver → gold → reports.

When you're done, run teardown.cmd from the same package and it'll tear down everything that was built.
